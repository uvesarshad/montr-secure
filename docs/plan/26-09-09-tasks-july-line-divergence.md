- [x] Treat A4 + A5 as a single "agentic remediation" epic, sequencing A4 first since A5 is unimplementable without it.
- [x] Add a CI job that runs the documented bring-up from a clean volume — closed by A10, which converts the existing integration-smoke job into exactly that test.
- [x] Retire the redundant backup branch — `backup/pre-rewrite-2026-09-09` deleted after confirming it was identical (same tip commit, zero divergence) to the pre-existing `archive-july-2026`.
- [x] Add a from-scratch deploy smoke test to the release path — now enforced automatically by the A10 CI job rather than left to a manual checklist.
- [x] Add a Windows CI leg, or drop the pretence. A2 and A6 are both Windows-only breakage that no current CI job would catch, so today's fixes will silently rot. Either test the platform or state plainly in the README that it is unsupported — the current in-between is the worst of the three options.
- [x] Decide whether to enable the A5 agent loop in production. It is built, tested and wired to nothing: `apps/worker/src/runners.ts` does not populate `agentLoop`, matching the existing `containerProof.targetRepoDir` precedent. Until someone turns it on, autonomous multi-file fixing — the point of the A4+A5 epic — stays dormant. Turning it on raises cost and latency per fix, so this is a deliberate call, not a default.
- [x] Fix the root lint entry point. `pnpm lint:root` (`eslint .`) reports ~11,400 errors, almost entirely under `apps/`, on files untouched by this work. The real per-package gate (`pnpm lint`, turbo) passes 37/37, so this is a misconfigured entry point rather than 11,400 genuine defects — most likely missing ignores for generated Next.js output. Needs its own pass; folding it into feature work would bury everything else in noise.
- [ ] **(A11, P0)** Investigate and fix the two golden-corpus false positives (one `sql_injection`, one `command_injection`) that appeared since the 2026-08-19 A17 recalibration. CI measures FP-rate 12.5% and precision 87.5% against `corpus/baseline.json`'s 5% / 90% thresholds, breaching three gates including `sql_injection`'s per-category `fpRateMax: 0`. Recall improved over the same period (25.0% -> 31.8%), so this is a precision regression, not a broad one. **Do NOT loosen the baseline** — its own header says tighten, never loosen; raising the ceiling would turn the accuracy gate into decoration. Not reproducible on macOS without `semgrep` installed (the local corpus scan finds nothing without it), so reproduce in CI or install semgrep locally first.
- [ ] **(A12, P1)** Fix real cross-platform path-handling bugs the Windows CI job surfaced — App Map route/model detection, HOC-wrap auth-boundary detection, telemetry-surfaces detection, and the golden-corpus loader (`resolves every repo to an existing absolute directory`) all fail on Windows with genuine assertion mismatches (routes/models resolving to `undefined` or empty arrays), not flakiness. This contradicts an earlier (untested) conclusion in the source audit that App Map path normalization was "fine, more thorough than July's" — that conclusion was never checked against a real Windows run until now, and it does not hold. Likely a single root cause (backslash vs forward-slash path comparisons somewhere upstream in the App Map builder) rather than four separate bugs, but that is not yet confirmed — investigate before assuming. Two more Windows failures are lower-priority and different in kind: `generate.agent-loop.test.ts` has two tests that only time out at the default 5000ms on the slower Windows runner (likely needs a longer timeout there, not a logic fix), and `fix.container-replay.test.ts` (the real-Docker proof-of-fix test) fails because GitHub's `windows-latest` runners do not have Docker available at all — that test needs excluding from the `windows` job's `pnpm test` step, not fixed.
- [ ] Flip the new `windows` CI job from `continue-on-error: true` to blocking once it has shown real green runs. Currently far from ready: the job's first real run (2026-09-09) failed on A12's genuine bugs, not day-one jitter — do not flip this until A12 is closed and the container-replay exclusion above is made.
